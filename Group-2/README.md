# Group 2 - Delivery Algorithms, Routing & Dispatch Engine

## Project

UG Smart Food Delivery & Dispatch Optimizer

This repository contains all algorithmic components responsible for searching, sorting, routing, rider dispatch, indexing, and optimization.

---

## Objectives

Develop every algorithm that powers intelligent food delivery across the University of Ghana campus.

---

## Scope

### Searching

Implement:

- Linear Search
- Binary Search

Search by:

- Restaurant
- Customer
- Rider
- Food Item
- Order ID

---

### Sorting

Implement:

- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort

Sort by:

- Price
- Delivery Time
- Rating
- Order Time
- Priority

---

### Indexing

Implement:

- Binary Search Tree
- Red-Black Tree
- B-Tree
- Hash Table

---

### Rider Dispatch

Implement:

- Priority Queue
- Heap

Dispatch riders based on:

- Distance
- Availability
- Urgency
- Estimated preparation time

---

### Campus Graph

Represent the University of Ghana road network using

- Adjacency List
- Adjacency Matrix

---

### Graph Algorithms

Implement

- BFS
- DFS
- Dijkstra
- Prim
- Kruskal

---

### Optimization

Implement

Greedy Algorithms

Dynamic Programming

Applications include:

- Rider assignment
- Delivery scheduling
- Batch deliveries
